## Featured Projects

### [PlantGuard](https://github.com/gabrielcarvalhosoa/PlantGuard)

Arduino-based system for soil monitoring and automated irrigation of a vegetable garden, developed for the *Interdisciplinary Project I* course at PUC Minas.

- Reads soil moisture (HD-38) and ambient temperature (DS18B20) simultaneously and classifies plant health in real time.
- Displays readings on a 16x2 I2C LCD and signals the overall status on an RGB LED, which always reflects the worst of the two conditions.
- Controls a relay-driven irrigation system automatically, with manual and automatic modes selectable from a mobile app over Bluetooth.

### [WeekndCar](https://github.com/gabrielcarvalhosoa/WeekndCar)

Web system for managing weekend rentals of classic cars in Belo Horizonte, developed for the *Web Interface Development* course at PUC Minas.

- Customers register, browse a filterable catalog, and create, modify, track, and cancel rental orders.
- Agents (companies and banks) evaluate orders financially, execute contracts, and grant credit.
- Integrates public APIs: ViaCEP (address lookup), Open-Meteo (weekend forecast), Wikipedia (vehicle history), and OpenStreetMap with Leaflet (pickup map).
- REST API simulated with JSON Server and consumed through the Fetch API, with UML documentation (use cases, user stories, class, package, and component diagrams).
